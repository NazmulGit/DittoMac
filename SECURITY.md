# Security policy

## Reporting a vulnerability
Please open a private security advisory at
`https://github.com/NazmulGit/DittoMac/security/advisories/new` rather than a public issue.
We aim to respond within 7 days.

## Design principles
DittoMac stores everything you copy, so it is treated as sensitive software.

| Area | Protection |
|---|---|
| Password managers | Clips marked `org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType` (and 1Password / other known markers) are never stored |
| Storage | SQLite DB in `~/Library/Application Support/DittoMac/` — directory `0700`, file `0600` |
| SQL | Every query uses bound parameters (enforced by a test that scans the sources) |
| Network ("Friends") | **Off by default.** Passphrase ≥ 12 chars stored in the Keychain; PBKDF2 (600k) PSK + ephemeral X25519 (forward secrecy) in an HMAC-authenticated handshake → per-session, per-direction ChaCha20-Poly1305 keys; strict frame counters (no replay/reorder); 16 MiB frame cap checked before allocation; no file-request feature; no connect-back to peer-supplied hosts |
| Code execution | No plug-in loading, no scripting engine. Upstream's ChaiScript and DLL add-ins are replaced by declarative Copy Rules |
| Regex | Input capped at 100k characters; invalid patterns are ignored |
| URLs | Web search / translate templates must be `https://`; clip text is percent-encoded via `URLComponents` |
| QR codes | Generated locally with CoreImage (upstream optionally used a web service) |
| Binary | Hardened runtime; universal (arm64 + x86_64) |

## Upstream issues not carried over
`docs/kb/security-review-upstream.md` lists the weaknesses found in Ditto 3.25.113.0 (Windows) during the port.
None of that C++ code is used here.

## Known limitations
- Release builds are **ad-hoc signed** (no Apple Developer ID), so macOS Gatekeeper asks you to confirm the first launch.
  The DMG's SHA-256 checksum is published with each release.
- The clip database is not encrypted at rest beyond file permissions and FileVault.
- Auto-paste needs the Accessibility permission. This is inherent to posting ⌘V into another app.
