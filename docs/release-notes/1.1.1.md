## DittoMac 1.1.1: drag several clips at once

### Fixed
- **Select several clips and drag them out.** Drop them on Finder, the desktop, Mail, Notes, Messages or any app:
  each clip arrives as a real file (image, `.rtfd`, `.rtf`, `.html` or `.txt`), and apps that accept pasted content
  also get the text, rich text or image directly. Clips copied from Finder are still dragged as the original files.
- Start-at-login re-points itself at the installed copy if the app was moved or reinstalled.

Install: download **`DittoMac-1.1.1-universal.dmg`**, drag to Applications and replace the old copy.
Universal build (Apple silicon + Intel), macOS 13+. Verify: `shasum -a 256 -c DittoMac-1.1.1-universal.dmg.sha256`
