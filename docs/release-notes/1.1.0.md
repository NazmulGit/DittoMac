## DittoMac 1.1.0: keep the full formatting

### New
- **Copies keep their full formatting.** When you copy from a website, Notes, Pages or Word, DittoMac now also saves
  **web archives** (page content with embedded images), **RTFD** (rich text with inline images), JPEG, GIF, HEIC, PDF
  and links, in addition to text, RTF, HTML and PNG. Paste into Notes, Pages, Mail and similar apps, and the headings
  (H1/H2/H3), styles, lists, links and images come back as they were.
- **Paste As ▸ / Copy As ▸** on any clip: *Original (keep all formatting)*, *Plain Text*, *Rich Text (no images)*,
  *Markdown* (headings, lists, links, tables and images converted), *HTML Source*.
- **Save Clip As…** (⌘⇧S): save as Rich Text (.rtf/.rtfd), Web Archive, HTML, Markdown, Plain Text or PNG. With
  several clips selected, saves one file per clip.
- **Default paste format** in Preferences › Quick Paste, plus **"Always paste plain text into these apps"** (for
  example Terminal or code editors).
- Keys: **⇧Return** pastes plain text, **⌥⇧Return** pastes Markdown.
- Rich clips show a small **Aa** badge in the list. The preview shows rich text with its images and lists the stored formats.

### Safety
Web archives and HTML are never rendered with WebKit. Previews and conversions never fetch remote content, and links
are limited to http(s)/mailto. Each format is capped at 64 MiB.

Install or update: download **`DittoMac-1.1.0-universal.dmg`**, drag it to Applications and replace the old copy.
It's a universal build for Apple silicon and Intel and needs macOS 13 or later.
Verify: `shasum -a 256 -c DittoMac-1.1.0-universal.dmg.sha256`
