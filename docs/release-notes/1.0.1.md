## DittoMac 1.0.1: Ditto for macOS

**New in 1.0.1:** DittoMac now starts with your Mac automatically (it registers as a login item on first launch; turn it off in Preferences › General or System Settings › Login Items).

DittoMac is a native macOS port of the Windows clipboard manager **[Ditto](https://github.com/sabrogden/Ditto) 3.25.113.0**.
It is a **universal app**: native on Apple silicon (M1, M2, M3, M4, M5) and on Intel Macs, and it needs **macOS 13 or later**.

### Install
1. Download **`DittoMac-1.0.1-universal.dmg`** below, open it, and drag DittoMac to Applications.
2. First launch: **right-click → Open** (the app is ad-hoc signed, not notarized), or run
   `xattr -dr com.apple.quarantine /Applications/DittoMac.app`.
3. Allow **Accessibility** for auto-paste (System Settings → Privacy & Security → Accessibility).
4. Press **⌃`** (Control + backtick) to open Quick Paste.

### Highlights
- Ditto's full workflow: history, search, groups, sticky clips, paste positions, special paste transforms,
  multi-paste, copy buffers, global hotkeys, themes, retention and properties.
- **Imports your Windows Ditto history** (`Ditto.db`).
- **Security first:** password-manager clips are never stored, all SQL is bound, there are no plug-ins or scripts,
  the database is `0600`, the binary uses the hardened runtime, and the optional LAN sync is end-to-end encrypted
  and off by default.

### Verify
```bash
shasum -a 256 -c DittoMac-1.0.1-universal.dmg.sha256
```
