# macOS platform notes (verified on this build host)

Host: Command Line Tools only (no Xcode.app), Swift 6.4.2, macOS 27.2 SDK, arm64.

## Build
- SwiftPM builds AppKit/SwiftUI/Carbon/SQLite3/CryptoKit/ServiceManagement/Network targets fine.
- **Universal binary (Apple silicon M1–M5 + Intel):**
  `swift build -c release --arch arm64 --arch x86_64` → `.build/out/Products/Release/<exe>`; check `lipo -archs`.
  Use `swift build -c release --arch arm64 --arch x86_64 --show-bin-path` for the path.
- Tests: **swift-testing** (`import Testing`) works; XCTest is NOT available with CLT only.
- Harmless linker warning: `search path '/Library/Developer/CommandLineTools/Developer/usr/lib' not found`.

## Bundle / icon / sign / DMG
- Hand-assembled `.app`: `Contents/MacOS/<exe>`, `Contents/Info.plist`, `Contents/Resources/AppIcon.icns`.
- Icon: render 1024 PNG with an AppKit script → `sips` into `.iconset` → `iconutil -c icns`.
- Ad-hoc sign w/ hardened runtime: `codesign --force --deep --options runtime --sign - X.app`.
  No Developer ID available → Gatekeeper warns on first open (right-click → Open, or `xattr -dr com.apple.quarantine`).
  Ad-hoc signatures change per build → Accessibility permission may need re-granting after updates.
- DMG: stage dir with app + `/Applications` symlink → `hdiutil create -format UDZO` → `hdiutil verify`.

## APIs
- Clipboard: poll `NSPasteboard.general.changeCount` every ~0.5 s (timer in `.common` mode, tolerance 0.1).
- Skip sensitive: `org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`,
  `com.agilebits.onepassword`, `de.petermaurer.TransientPasteboardType`, `com.typeit4me.clipping`, `Pasteboard generator type`.
- Own writes: tag with `org.dittomac.internal` and remember changeCount to avoid re-capture.
- Paste: re-activate previous `NSWorkspace.frontmostApplication`, wait ~80 ms, post Cmd+V via `CGEvent`
  (`kVK_ANSI_V`, `.maskCommand`, `.cghidEventTap`). Needs Accessibility (`AXIsProcessTrustedWithOptions`).
  Without it: clip is placed on clipboard and the user is told to press ⌘V.
- Global hotkeys: Carbon `RegisterEventHotKey` (no Accessibility needed).
- Launch at login: `SMAppService.mainApp.register()` (works only from a real bundle).
- Popup position: at mouse (`NSEvent.mouseLocation`) clamped to the screen's `visibleFrame`; caret via AX when available.
