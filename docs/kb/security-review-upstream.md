# Upstream Ditto security review (3.25.113.0) and port decisions

Static review of `sabrogden/Ditto` @ 3.25.113.0 (commit 81a667c). Nothing was exploited at runtime.
No published CVE for Ditto was found. Upstream has no `SECURITY.md`.

## Findings in upstream (Windows) code

| # | Severity | Issue | Upstream location | macOS port decision |
|---|---|---|---|---|
| W1 | Critical | "Friends" listener on by default on `0.0.0.0:23443`, default password `LetMeIn`, stored in plaintext | `Options.cpp:2034,1603,2986` | Off by default; passphrase required (min 12 chars), stored in Keychain |
| W2 | Critical | `REQUEST_FILES` lets a peer make the server read **any local path** it names (plus UNC → NTLM leak) | `Server.cpp:374`, `FileSend.cpp:49-125` | File requests **removed**; only text/RTF/HTML/image payloads |
| W3 | Critical | Stack overflow: `DragQueryFile(..., sizeof(file))` passes bytes as char count | `FileSend.cpp:54,58`, `Clip.cpp:708` | N/A (Swift, bounds-checked) |
| W4 | High | File contents sent unencrypted | `FileSend.cpp:147` | All frames AEAD-encrypted |
| W5 | High | Pre-auth CPU DoS: KDF round count read from wire | `Encryption.cpp:185` | KDF params fixed locally, never from wire |
| W6 | High | AES-CBC per frame, no MAC/session binding → replay/reorder | `SendSocket.cpp` | ChaChaPoly AEAD, per-session random salt, per-direction keys, counter nonces |
| W7 | Medium | Unkeyed SHA-256 of plaintext sent in clear (guess oracle) | `Encryption.cpp:90` | Removed |
| W9/W10 | Medium | Peer-controlled allocation sizes; unbounded accumulation | `RecieveSocket.cpp:51` | Hard caps: 16 MiB/frame, 64 formats, connection limit |
| W11-W15 | Medium | Peer-chosen format names, untrusted strings, connect-back to peer-claimed hostname, clipboard hijack by claimed name | `Server.cpp`, `Client.cpp` | Identity = authenticated key only; no connect-back; peer strings display-only |
| W16 | Low | Received files saved to temp with any extension, no cleanup | `FileRecieve.cpp` | No file receive |
| W17 | Low | Password logged in clear | `RecieveSocket.cpp:95` | Never log secrets |
| S1 | High (local) | ChaiScript on-copy scripts can `load_module`/`eval_file` (native code exec) | `ChaiScriptOnCopy.cpp:32` | Replaced with declarative **Copy Rules** (match app/regex → ignore/strip/sticky); regex input length capped |
| S2 | High (local) | Add-in DLLs loaded from `Addins\*.dll` with no signature check | `DittoAddins.cpp:40` | Dropped; useful add-in functions built in. Hardened runtime blocks unsigned dylib loading |
| S3 | Medium | SQL built by string concat; format names read back unescaped (2nd-order injection) | `CP_Main.cpp:1075`, `DittoRulerRichEditCtrl.cpp:82` | All SQL uses bound parameters; LIKE escaping with `ESCAPE '\'` |
| S4 | Medium | Web search URL built with `InternetCanonicalizeUrl` (not component encoding) + `lstrcat` overflow in `GotoURL` | `Misc.cpp:1375`, `HyperLink.cpp:421` | `URLComponents` + percent-encoding; only `https` templates accepted |
| S5 | Low | QR code generated via hosted web service (leaks clip) | `QPasteWnd.cpp:4340` | Local CoreImage `CIQRCodeGenerator` only |
| S6 | Medium | No password-manager clip filtering | `MainFrm.cpp:1046` | Honour `org.nspasteboard.ConcealedType/TransientType/AutoGeneratedType`, 1Password & others; excluded-apps list |
| S7 | Low | Temp files predictable, never cleaned | `Options.cpp:528` | Edits happen in-app; no temp files for clips |
| S8 | Info | DB history unencrypted | `CppSQLite3.cpp:804` | DB in `~/Library/Application Support/DittoMac`, dir `0700`, file `0600` |

## Responsible disclosure note
W2, W3, W5, S3 and the `GotoURL` overflow look like candidates for disclosure to the upstream maintainer.
They are not confirmed at runtime.
