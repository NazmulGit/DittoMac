# Lightshot parity (research notes, 2026-11-25)

Sources: app.prntscr.com, lightshot.org, third-party guides (tutorialtactic.com, techquintal.com). The official pages are thin;
items marked (guide) come from third-party guides.

| Lightshot feature | DittoMac plan |
|---|---|
| Drag to select an area, resize with handles, pixel precision | Overlay with handles, move, arrow-key nudge, live size and magnifier |
| Select whole screen with ⌘A / Ctrl+A (guide) | ⌘A in the overlay |
| Instant full-screen save / upload hotkeys (guide) | "Capture Full Screen" hotkey with the default action (copy / save / upload) |
| Hold ⌘ while releasing the drag to copy immediately (guide) | Same |
| Esc cancels | Esc |
| Tools: pen, line, arrow, rectangle, text, marker, colour picker, crop (guide) | All of them, plus blur/pixelate, numbered steps, ellipse; undo/redo |
| Actions: save (⌘S), copy (⌘C), upload (⌘D), social share, search similar, print, edit online (⌘E), close (guide) | Save, copy, upload and share by link, social web-intents, search similar (Google Lens by URL), print, close; "edit online" is replaced by the built-in editor |
| Settings: hotkey, PNG/JPG/BMP, default folder, cursor capture, run at startup | All of these |
| prnt.sc upload and gallery | Not available: no public API. Replaced by user-chosen upload providers |
| Browser extensions | Out of scope |
